2. Pravidla pro vysílání číselných údajů

Následující pravidla popisují způsob vysílání jednotlivých druhů číselných údajů v radiotelefonním provozu.

📡 Volací znak, kurz, dráha a vítr

Všechna čísla se vysílají vyslovováním každé číslice odděleně.

Příklad Výslovnost
OK-ABC OK ALFA BRAVO CHARLIE
Kurz 358° TŘI PĚT OSUM
Kurz 050° NULA PĚT NULA
Dráha 27 DVA SEDUM
Dráha 30 TŘI NULA
Vítr 200° / 70 kt vítr DVA NULA NULA stupňů SEDUM NULA uzlů

🛫 Letové hladiny (FL)

Vysílají se po jednotlivých číslicích, s výjimkou celých stovek (použije se STO / STA / SET).

Výjimka: Celé stovky se vysílají jako STO / STA / SET.

Příklad Výslovnost
FL 180 JEDNA OSUM NULA
(nebo: letová hladina JEDNA OSUM NULA)
FL 200 DVA STA
(nebo: letová hladina DVA STA)

🌡 Nastavení výškoměru (QNH)

Vysílají se po jednotlivých číslicích, s výjimkou hodnoty 1 000 hPa („JEDEN TISÍC“).

Výjimka: Hodnota 1 000 hPa se vysílá jako JEDEN TISÍC.

Příklad Výslovnost
QNH 1009 JEDNA NULA NULA DEVĚT
QNH 1000 JEDEN TISÍC
QNH 993 DEVĚT DEVĚT TŘI

📟 Kódy odpovídače (Squawk)

Vysílají se po jednotlivých číslicích, s výjimkou celých tisíců („TISÍC“ / „TISÍCE“).

Výjimka: Celé tisíce se vysílají jako TISÍC nebo TISÍCE.

Příklad Výslovnost
2400 DVA ČTYRY NULA NULA
1000 JEDEN TISÍC
2000 DVA TISÍCE

📏 Ostatní číselné údaje

Pro výšku (altitude), dohlednost, RVR a oblačnost. Vysílají se po jednotlivých číslicích, celých stovkách a tisících.

Příklad Výslovnost
800 OSUM SET
3 400 TŘI TISÍCE ČTYRY STA
12 500 JEDNA DVA TISÍCE PĚT SET
Dohlednost 1000 dohlednost JEDEN TISÍC
Dohlednost 700 dohlednost SEDUM SET

⏰ Doplňující pravidla

Příklad Výslovnost
Čas 20 (UTC) DVA NULA
Čas 0920 (UTC) NULA DEVĚT DVA NULA
Pozice 10:00 DESET HODIN
Pozice 11:00 JEDENÁCT HODIN
100,3 (Desetinná čárka) JEDNA NULA NULA ČÁRKA TŘI

Poznámky: Čas se běžně uvádí pouze minutami (při nebezpečí omylu i s hodinami). Relativní zaměření na ciferníku se vyslovuje spojitě.
