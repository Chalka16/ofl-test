🔢 Čísla v radiotelefonním provozu

Správná výslovnost čísel je jedním ze základních prvků radiotelefonního provozu. Používá se při předávání kurzů, výšek, frekvencí, letových hladin, volacích znaků, kódů odpovídače i dalších provozních údajů.

📌 Základní pravidlo

Většina čísel se vysílá vyslovováním každé číslice samostatně.

Výjimky tvoří pouze případy stanovené předpisem (letové hladiny, QNH/QFE, kódy odpovídače, výšky, dohlednost a některé frekvence).

🔢 Výslovnost číslic

Česká radiotelefonní korespondence používá českou výslovnost číslic. U některých číslic je výslovnost odlišná od běžné češtiny, aby se zabránilo jejich záměně při zhoršené kvalitě spojení.

⚠️ Odlišnosti české výslovnosti

Pouze tři číslice mají v české radiotelefonii odlišnou výslovnost oproti běžné češtině. Důvodem je lepší srozumitelnost při rádiovém spojení.

Běžná čeština Radiotelefonie
ČTYŘI ČTYRY
SEDM SEDUM
OSM OSUM

💡 Zapamatuj si

  • ✔ Většina čísel se vysílá po jednotlivých číslicích.
  • ✔ Nejčastější chybou je použití běžné české výslovnosti místo radiotelefonní.
  • ČTYŘI → ČTYRY
  • SEDM → SEDUM
  • OSM → OSUM
  • ✔ Slovo ČÁRKA se používá při vyslovování desetinných míst frekvencí.
  • ✔ Slova STO a TISÍC se používají pouze v případech stanovených předpisem.

✈️ Výjimky ze základního pravidla

Základním pravidlem radiotelefonní korespondence je vyslovování každé číslice samostatně.

Existují však situace, kdy se místo jednotlivých číslic používají slova STO nebo TISÍC.

📌 Zapamatuj si

Výjimky se týkají pouze přesně stanovených údajů:
  • ✔ Letové hladiny (FL)
  • ✔ Nastavení výškoměru QNH / QFE
  • ✔ Kódy odpovídače (Squawk)
  • ✔ Nadmořské výšky
  • ✔ Výšky oblačnosti
  • ✔ Dohlednosti
  • ✔ Dráhové dohlednosti (RVR)

🛫 Letové hladiny (Flight Level)

Letové hladiny se běžně vysílají po jednotlivých číslicích. Výjimkou jsou pouze celé stovky.

Zápis Radiotelefonní výslovnost
FL 080 Letová hladina NULA OSUM NULA
FL 180 Letová hladina JEDNA OSUM NULA
FL 200 Letová hladina DVA STA
FL 300 Letová hladina TŘI STA
💡 Pozor

Celé stovky se u letových hladin nevyslovují po číslicích.

🌡 Nastavení výškoměru (QNH / QFE)

Nastavení výškoměru se vysílá po jednotlivých číslicích. Výjimkou je pouze hodnota 1000 hPa.

⛰️ Výšky, dohlednost a oblačnost

Nadmořské výšky, výšky oblačnosti, dohlednost a dráhová dohlednost mají vlastní pravidla vysílání.

📌 Pravidlo

Celé stovky a celé tisíce se vysílají pomocí slov STO a TISÍC.

Kombinace tisíců a stovek se vysílá jako:

počet tisíců + TISÍC + počet stovek + STO

📻 Hláskování frekvencí

Při vysílání frekvencí se používá všech šest číslic označení kanálu. Desetinná čárka se vyslovuje jako ČÁRKA.

💡 Výjimka

Pokud jsou pátá i šestá číslice nuly, vyslovují se pouze první čtyři číslice.

📝 Shrnutí kapitoly

  • ✔ Základním pravidlem je vyslovování každé číslice samostatně.
  • ✔ ČTYŘI, SEDM a OSM mají odlišnou radiotelefonní výslovnost.
  • ✔ Letové hladiny, QNH, Squawk, výšky a dohlednost mají stanovené výjimky.
  • ✔ Frekvence se vysílají podle pravidel pro označení kanálu.
  • ✔ Nejčastější chybou je použití běžné české výslovnosti nebo vysílání čísel po jednotlivých číslicích tam, kde se používá STO nebo TISÍC.
